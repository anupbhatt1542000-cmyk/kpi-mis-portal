# KPI & MIS Portal

A web-based KPI and Management Information System (MIS) portal built with React, Vite, Node.js, Express, Sequelize, and MySQL.

## Project Structure

- `client/` — Frontend application
- `server/` — Backend API
- `deploy/` — Deployment configuration

## Prerequisites

- Node.js
- MySQL
- npm

## Setup

1. Install dependencies in the `client` and `server` directories.
2. Configure the backend using your own environment variables.
3. Use a separate development database.
4. Start the backend and frontend using the project's configured scripts.

## Security

- Never commit passwords, tokens, `.env` files, database backups, or real organizational data.
- Use fictional data for demonstrations.
- Configure unique credentials and secrets for each deployment.

This repository is a sanitized code-sharing copy. Real organizational data and private configuration files are intentionally excluded.
